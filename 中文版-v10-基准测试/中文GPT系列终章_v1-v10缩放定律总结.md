# 中文 GPT 从零训练系列终章：v1–v10 缩放定律总结

- 日期：2026-09-08
- 硬件：RTX 4060 Laptop（8GB 显存），单卡全程
- 系列跨度：v1（10.7M 参数，val 4.11）→ v10（234.5M 参数，永久基准 3.1819）
- 本文是收官总结：从**模型缩放（Scaling Laws）视角**复盘全部十轮实验，并回答两个终极问题——固定模型最大能吃多少数据？参数 / 数据 / 步数如何匹配？

## 一、系列全景：三条杠杆各自的收益实证

缩放只有三条杠杆：**参数量 N、数据量 D、训练步数（等价于 epoch 数 E）**。十轮实验每一轮恰好只压一条（除了 v7 的反面教材），收益全部可归因：

| 版本 | 改动的杠杆 | N | 训练 token D | E | 成绩 | 净收益 |
|---|---|---|---|---|---|---|
| v1 | —（起点） | 10.7M | 0.36亿字符 | 高 | val 4.11 | — |
| v3 | **数据** ×4.6 | 10.7M | 1.66亿字符 | — | val 3.38 | **-0.73** |
| v4 | **模型** ×9 | 96.1M | 1.66亿字符 | — | val 3.1274 | -0.25（字符级口径） |
| v5 | 分词器（BPE） | 109.8M | 0.12亿 token | 虚高 | 5.1436 | 回归 ⚠️ |
| v6 | **数据** ×6 + BPE 定型 | 109.8M | 0.66亿 token | 2.46 | 基准 3.7545 | 确立基线 |
| v7 | 同时改 5 个变量 | 218M | 0.66亿 | 4.92 | val 4.6961 | **回归 ⚠️（纪律事故）** |
| v7.1/7.2 | 消融 | 234.5M/218M | 0.66亿 | 1.23 | — | 定罪权重共享 |
| v8 | **模型** ×2.1 | 234.5M | 0.66亿 | 2.46 | 基准 3.4805 | **-0.274** |
| v9 | **步数** ×1.6（E→3.94） | 234.5M | 0.66亿 | 3.94 | 基准 3.4175 | **-0.063** |
| v10 | **数据** ×3（E→1.31） | 234.5M | 2.0亿 | 1.31 | 基准 **3.1819** | **-0.236** |

（v6 起统一为永久基准集口径：9944 万 token 冻结集，所有模型均未见过；v5 及更早为各自历史口径，仅作趋势参考）

### 三条杠杆的边际收益曲线（本系列实测）

```
数据杠杆（新鲜数据）：v6→v10 方向    -0.57 累计，未见明显衰减 ← 当前性价比之王
模型杠杆（N 翻倍级）：v6→v8          -0.274 / 次（数据跟得上时稳定兑现）
步数杠杆（E 堆高）：v8→v9           -0.063 / 次（E→4 时收益已缩水 77%）
```

**核心结论：在 8GB 单卡尺度下，边际收益排序为 新鲜数据 > 模型扩容 > 重复训练。** v9 把同一份数据多嚼 1.6 遍只赚 0.063，v10 换成 3 倍新鲜数据立刻赚 0.236——重复数据的边际和新鲜数据的边际差了 4 倍。

## 二、问题一：固定参数的模型，最大能吃多少数据？

### 2.1 数据无限时：没有上限，但有「该换杠杆」的临界点

Loss 随数据量按幂律下降，永不到零。但 Chinchilla 算力最优配比给出分水岭：

```
D_optimal ≈ 20 × N
```

对 N = 234.5M：**D ≈ 47亿 token ≈ 63亿中文字符**。本系列最大只喂到 2.0亿 token（4%）——换句话说，这个模型到死都在「数据饥饿」状态，所谓「吃不下」在这个尺度不存在。过了 20N 之后，同样算力投给扩 N 更划算；没到 20N 之前，加数据永远是正确动作。

### 2.2 数据有限时（真实场景）：上限 = 4 倍独特数据

独特数据 T 固定时，能吃的总量由数据受限缩放定律（Muennighoff et al., 2023）封顶：

```
D_max ≈ 4 × T        （E ≤ 4：重复收益 ≈ 新鲜数据）
                     （E > 4：急剧衰减；E > 16：近乎归零）
```

**本系列的实测验证**：

| 证据 | 数据 |
|---|---|
| v8 → v9（E 2.46 → 3.94，纯重复） | 基准 -0.063，且 val 在 29200 步后连续 7 次评估不再创新低——天花板信号完整出现 |
| v9 → v10（E 3.94 → 1.31，换 3 倍新鲜数据） | 基准 **-0.236**，同样算力下收益 4 倍于重复 |
| v5（E 虚高不扩数据） | 直接回归，epoch 通胀的反面教材 |

对 T = 2.0亿 token（0.3b 语料）：D_max ≈ 8亿 token ≈ 98000 步（batch 32 × block 256）。v10 只训了 32000 步（E=1.31），**这份语料其实还能再训 3 倍的步数才到顶**——只是硬件时间成本已经不划算。

## 三、问题二：参数、数据、步数的最优匹配

### 3.1 三个基本公式

```
C ≈ 6ND                    训练算力（FLOPs）
D = 步数 × batch_size × block_size
E = D / T                  epoch 数（T = 独特训练 token）
```

### 3.2 匹配工作流（本系列沉淀的决策顺序）

```
第 1 步：N 由显存定死
         静态显存 ≈ 16 字节 × N（fp32 参数 + 梯度 + AdamW 的 m,v）
         另加 fp16 副本 2N 与激活值；8GB 卡实测上限 ≈ 2.5 亿参数 ✓（234.5M 跑在 6464 MiB）

第 2 步：D 取两个约束的较小值
         算力最优：D = 20N（数据管够时）
         数据封顶：D = 4T（数据有限时，T = 去重后的独特 token 数）

第 3 步：步数被动确定，一次定终身
         max_iters = D / (batch_size × block_size)
         余弦 schedule 按 max_iters 规划，开跑后绝不能改（改了整条曲线作废）

第 4 步：训练中用两个信号验收
         ① val 连续多次评估不创新低 + train 仍降 → 数据到顶（v9 实测：连续 7 次）
         ② 过拟合间隙 > 0.2 → E 偏高或 N 偏大
```

### 3.3 本系列的四个终态配比案例

| 案例 | N | T | E | 判定 |
|---|---|---|---|---|
| v6 | 109.8M | 0.66亿 | 2.46 | 均衡健康，基线 |
| v8 | 234.5M | 0.66亿 | 2.46 | 模型超前于数据（D/20N=0.035），但仍赚 -0.27——**远离算力最优前沿时，超配模型依然划算** |
| v9 | 234.5M | 0.66亿 | 3.94 | 顶到数据天花板，收益枯竭 |
| v10 | 234.5M | 2.0亿 | 1.31 | 数据追上模型，最健康配比，最大单轮收益 |

## 四、十条军规（十轮实验的最终沉淀）

1. **一次只改一个变量**——v7 改 5 个烧掉 663 分钟还倒退，v7.1/v7.2 两次消融才定罪权重共享
2. **不要用权重共享（tying）**——在本配方（AdamW wd=0.1 + 0.02 初始化）下实测有毒，v8 翻案
3. **E ≤ 4** 是数据复用的硬上限，接近时收益曲线肉眼可见地躺平
4. **新鲜数据 > 重复数据 > 堆步数**，加杠杆前先问数据是不是真的用完了
5. **换语料必换尺子**：验证集必须独立于所有训练语料，永久冻结，否则 -0.28 的大胜可能只是集子变易（v10 误诊事件）
6. **评估脚本三要素**：打印被测模型路径、结构参数用探针从 checkpoint 反读、无硬编码默认值
7. **语料扩充先体检**：重复率 + 与既有语料的包含关系（0.3b ⊇ 0.1b 的 100% 包含是实锤教训）
8. **best-checkpoint 机制永远开着**：v9 的 final 比 best 差 0.057，余弦收尾段出最优是常态
9. **预登记预测**：每轮开跑前写下预期区间，落空时必须解释——本系列两次反转（v7、v10 初判）都是被预测逼出来的
10. **显存不是瓶颈，时间是**：16 字节 × N 公式 + 梯度检查点，8GB 卡足以支撑 234M 模型健康训练；真正的极限是每轮 15~18 小时的耐心等待
