# 中文字符级 GPT 模型训练总结（v6：BPE + 语料扩容，新基线诞生）

> 训练时间：2026-09-02 14:45 ~ 19:43 ｜ 硬件：RTX 4060 Laptop（8G 显存, CUDA）｜ 框架：PyTorch + sentencepiece
> 前序实验见：《中文GPT模型训练总结.md》及 v2~v5 各版
> **实验设计：与 v5 唯一的变量是语料规模（1239 万 token → 7386 万 token，×6），分词器、模型结构、超参全部保持一致**

## 一、训练配置与数据集

### 1.1 模型与训练配置（与 v5 完全相同）

| 参数 | 值 |
|---|---|
| 分词器 | sentencepiece BPE，词表 16000（含 [BR] 换行符 + 256 字节兜底） |
| n_layer / n_embd / n_head | 12 / 768 / 12 |
| block_size / dropout | 256 / 0.2 |
| 参数量 | 109,816,960（约 1.098 亿） |
| batch_size / max_iters | 64 / 10000 |
| 学习率 | warmup 100 步 + 余弦衰减 3e-4 → 3e-5 |
| 优化器 / 精度 | AdamW（wd=0.1）/ AMP FP16 + Flash Attention + 梯度检查点 |

### 1.2 数据集（本轮核心变化）

| 项 | v5（对照） | **v6（本轮）** |
|---|---|---|
| 语料总量 | 12,392,605 token（1866 万字符） | **73,862,951 token（按 1.51 压缩比反推约 1.1 亿字符，×6）** |

### 2.4 结论

1. **组合收益完整兑现**：每字符 val loss 从 v4 的 3.13 降至 **2.54，降幅 19%**，六轮实验最大单次跃升。v5 被过拟合掩盖的 BPE 收益，在数据充足后全部释放；
2. **曲线形态教科书级健康**：train/val 全程贴合同步下降，终态裂口仅 0.16（v5 高达 0.94）。2.5 个 epoch 下模型在「学习」而非「背诵」；
3. **v5 的归因被证实**：唯一的变量就是语料 ×6，过拟合立即消失——数据瓶颈诊断完全正确；
4. **余量仍在**：9500 步后 val 仍在小幅波动下行（3.8536 → 3.8296 → 3.8603），学习率已触底，曲线末端尚未完全走平——同样配置下再加数据或加步数都还有空间；
5. **v6 成为新基线**，取代 v4。

## 三、优化建议

### 3.1 短期（不重训，立即可做）

- **生成质量人工验收**：用 temperature 0.8~1.0 + top-k 50~200 采样生成几段文本，对比 v4 的生成——本轮 loss 降幅 19% 应该在可读性上有肉眼可见的提升；
- **保存最优 checkpoint 的习惯固化**：本轮最优 val 在 9500 步而非 9999 步，建议在训练循环里加「val 创新低才存盘」逻辑。

### 3.2 中期（下一轮 v7 的候选方向，按性价比排序）

1. **继续加步数**：6648 万训练 token 只跑了 2.5 epoch，远没到数据极限。max_iters 提到 15000~20000（余弦 schedule 相应重设），预计再降 0.05~0.1，成本只是多跑 2~3 小时；
2. **扩模型到 2 亿参数级**：数据已足够喂养更大模型。可试 n_layer=16 / n_embd=1024（约 2 亿参数），有梯度检查点 + AMP 托底，显存峰值估计 7GB 上下，需要把 batch_size 回调到 48~64 之间找平衡；
3. **加长上下文**：block_size 256 → 512，配合现有语料规模，让模型学会段落级结构。

### 3.3 长期（架构级）

- **权重共享**：`lm_head.weight = token_embd.weight`，省 1230 万参数（占总量 11%），通常还小幅提质；
- **验证集改为随机抽样切分**：当前「前 90% 训练 / 后 10% 验证」按位置切分，验证集与训练集文本难度分布有系统性差异，随机切分后 val loss 更真实；
- **向生产级架构演进**：RMSNorm、SwiGLU、RoPE 位置编码是现代 LLM（LLaMA 系）标配，学有余力时可逐项替换实验。

## 附：六轮实验演进路线

```
v1 (408万字, 3150万参数)  ──► val 4.11/字符 ── 过拟合 0.75
        │ 扩语料 ×4.6
v3 (1866万字, 3260万参数) ──► val 3.38/字符 ── 裂口消除
        │ 扩模型 ×3
v4 (1866万字, 9610万参数) ──► val 3.13/字符 ── 字符级天花板
        │ 换 BPE（数据不变）
v5 (1866万字, 1.1亿参数)  ──► val 3.41/字符 ── 过拟合 0.94，证明数据是瓶颈
        │ 扩语料 ×6
v6 (1.1亿字,  1.1亿参数)  ──► val 2.54/字符 ── 新基线 ✓
```

**方法论总结**：v1→v6 完整走了一遍「数据 → 模型 → 分词 → 数据」的交替优化路径，每轮只改一个变量，用每字符 loss 做统一度量——这条实验纪律是六轮迭代始终能定位因果的关键。
