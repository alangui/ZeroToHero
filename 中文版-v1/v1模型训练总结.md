## 二、训练效果

### 2.1 Loss 变化记录

| 步数 | train loss | val loss | 裂口 |
|---|---|---|---|
| 0 | 8.8742 | 8.8730 | 0.00 |
| 500 | 4.8849 | 4.9450 | 0.06 |
| 1000 | 4.4352 | 4.5446 | 0.11 |
| 1500 | 4.1832 | 4.3707 | 0.19 |
| 2000 | 4.0212 | 4.2600 | 0.24 |
| 2500 | 3.8713 | 4.2025 | 0.33 |
| 3000 | 3.7524 | 4.1618 | 0.41 |
| 3500 | 3.6390 | 4.1315 | 0.49 |
| 4000 | 3.5404 | 4.1101 | 0.57 |
| 4500 | 3.4518 | 4.1112 | 0.66 |
| **4999** | **3.3626** | **4.1092** | **0.75** |

随机猜测基线：ln(6200) ≈ **8.73**。最终 val loss 4.11，对应困惑度（perplexity）约 61。

### 2.2 训练开销

- 总耗时：约 **121 分钟**（MPS GPU 加速）
- 平均每步：约 1451 毫秒
- 每次 loss 评估（100×2 次前向）：约 73 秒

### 2.3 结论

1. **val loss 在 3500 步后进入平台期**（4.13 → 4.11，仅降 0.02），后 1500 步训练几乎无收益；
2. **train/val 裂口持续扩大至 0.75**，呈典型过拟合形态——模型在反复背诵训练集；
3. 与 1530 万参数的较小模型对比（val 4.21），参数翻倍仅换来 0.1 的 val 提升，**模型容量已过剩，数据量是主要瓶颈**；
4. 生成效果：汉字、词语基本正确，短句有小说语感，长句逻辑混乱——符合该 loss 水平的预期。

## 三、优化建议

### 3.1 不换数据即可做（预期 val 4.11 → 3.9~4.0）

1. **提前停止**：`max_iters` 改为 3000，节省约 40% 训练时间；
2. **学习率衰减**：加入 warmup + 余弦衰减（3e-4 → 3e-5），标准 GPT 训练配置，预计收益 0.1~0.2；
3. **加重正则化**：dropout 0.2 → 0.3，AdamW 加 `weight_decay=0.1`，收窄过拟合裂口后再足量训练。

### 3.2 扩大数据（质变的关键，预期 val → 3.3~3.5）

- 将语料从 mini 版（400 万字）升级到 **AMC 完整版小说分库（8300 万字符）**，或自行合并多本小说至 1000 万字以上；
- 清洗语料：去除隐形字符（`\u200a`、`\u200b`）、外文字母、拼音符号，压缩连续空行；词表单独存档保证训练/推理一致。

### 3.3 长期方向

- **BPE 分词**（sentencepiece / tiktoken）：中文按字建模天然吃亏，换子词分词后生成质量会有方向性提升（注意 loss 数值口径变化，不可与字符级直接比较）；
- 数据到位后可将模型扩至 n_layer=10+、n_embd=640+，并训练 1 万步以上。

### 3.4 诊断方法沉淀

| Loss 曲线形态 | 诊断 | 处方 |
|---|---|---|
| train/val 贴合且都在快速下降 | 欠拟合 | 加步数、加大模型 |
| **train 降、val 平、裂口扩大（本次）** | **数据不足 / 过拟合** | **加数据、加正则、提前停** |
| 两条都平且都很高 | 配置问题 | 调学习率、查模型结构 |
