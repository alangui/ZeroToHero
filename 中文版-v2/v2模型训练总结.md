### 2.2 与 v1 对照

| 指标 | v1（dropout 0.2，固定 lr） | v2（dropout 0.3 + 余弦衰减） | 解读 |
|---|---|---|---|
| 最终 train loss | 3.36 | 3.80 | 正则化压制了"背诵"，train 升高是预期现象 |
| 最终 val loss | **4.1092** | 4.1354 | **基本持平** |
| train/val 裂口 | 0.75 | **0.34** | 过拟合大幅缓解 |
| val 平台期起点 | ~3500 步 | ~4000 步 | 衰减让平台期延后，但未突破下限 |
| 总耗时 | 121 分钟 | 120 分钟 | 持平 |

### 2.3 结论

1. **正则化目标达成**：裂口从 0.75 收窄到 0.34，模型从"背训练集"转向"正常学习"；
2. **但 val loss 天花板未被突破**：两种训练状态（背诵型 / 正则化型）收敛到同一水平（4.11 vs 4.14），证实 **~4.1 是当前 400 万字数据支撑的能力上限**，调参空间已榨干；
3. 学习率衰减的轨迹符合设计（日志中 lr 从 3.00e-4 平滑降至 3.00e-5），机制本身工作正常，只是当前瓶颈不在此处；
4. 至此完成了一次完整的 Scaling Laws 实践：**模型、数据、算力必须匹配，单拉任何一项都会撞墙**。

## 三、优化建议（按预期收益排序）

### 3.1 更换分词方式：BPE（不换数据，下一步首选）

- 用 `sentencepiece` 在清洗后语料上训练约 8000 词表的 BPE 分词器，替换现有字符级 `encode/decode`；
- 收益机制：① 同样的 block_size=256，上下文实际覆盖文字量提升近一倍；② 常见词整体建模，不再浪费容量逐字猜词；
- 注意：分词粒度改变后 loss 口径变化，不能与 4.1 直接比较，**以生成文本质量为裁判**。

### 3.2 扩大数据集（质变关键，预期 val → 3.3~3.5）

- 升级至 AMC 完整版小说分库（8300 万字符），或自行合并多本小说至 1000 万字以上；
- 沿用已沉淀的 `prepare_data.py` 清洗流程 + `vocab.json` 词表存档机制。

### 3.3 数据到位后的训练配置

```python
n_layer = 8          # 可试 10
n_embd  = 512        # 可试 640（n_head 同步调 10，head_size 仍 64）
dropout = 0.2        # 数据充足后回调
max_iters = 10000    # 配合余弦衰减全程训练
```

### 3.4 暂缓项

- 继续调 dropout / lr / 步数：本轮已证明收益趋零；
- 缩小模型：v1 对照表明小模型 val 更差（4.21），方向不对。
